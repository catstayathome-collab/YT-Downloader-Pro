# YT Downloader Pro Windows 1.8.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an unsigned portable Windows 10/11 x64 edition of YT Downloader Pro 1.8.7 with the same single-video workflow and safety behavior as the macOS 1.8.7 release.

**Architecture:** Extract platform-independent models, filename allocation, settings, update parsing, and yt-dlp option construction into a focused `ytdp` package. Keep Tkinter orchestration shared while platform adapters provide paths, helper names, language detection, subprocess flags, and executable validation. Build and self-test the Windows onedir package on GitHub Actions using pinned x64 helpers.

**Tech Stack:** Python 3.13, Tkinter, yt-dlp 2026.6.9, yt-dlp-ejs 0.8.0, certifi 2026.1.4, PyInstaller 6.21.0, unittest, GitHub Actions `windows-2022`, BtbN FFmpeg x64 LGPL, Deno 2.8.1 x64.

## Global Constraints

- Display version remains exactly `1.8.7` on both platforms.
- Windows support is Windows 10 22H2 or newer and Windows 11 on Intel/AMD x64 only.
- The deliverable is `YT-Downloader-Pro-v1.8.7-Windows-x64.zip`, initially an unsigned GitHub Actions artifact.
- Windows uses only `Helpers/ffmpeg.exe`, `Helpers/ffprobe.exe`, and `Helpers/deno.exe`; it never falls back to system-installed tools.
- macOS `YT_downloader_187.py` behavior and all existing tests must remain green.
- Settings contain only output directory and language; logs never contain cookies, credentials, or tokens.
- Production behavior changes follow test-first red, green, refactor cycles.
- The Windows ZIP is not attached to the public `v1.8.7` Release until manual Windows 11 acceptance passes.
